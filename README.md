# Actualizaciones SANTANI PRUEBAS

Canal público utilizado por **SANTANI PRUEBAS Updater.exe** para descargar versiones verificadas automáticamente.

Este repositorio contiene únicamente fragmentos binarios del programa compilado y su manifiesto de integridad. No contiene código fuente, bases de datos, ventas, clientes, backups ni configuraciones del negocio.

Los fragmentos de la carpeta `files` no son ejecutables por separado. El actualizador oficial los reconstruye y valida mediante SHA-256 antes de instalar una versión.
